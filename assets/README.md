# assets

Intentionally empty of brand marks.

Neither source (`risadams/vs-ris` BRAND.md, `cathrynlavery/diagram-design`) ships a logo,
wordmark, icon font or illustration set, so none was drawn or reconstructed here. Where a
mark would go, set the name in Fraunces 400 at `-0.02em` tracking.

Fonts are Google-hosted (Fraunces, Caveat, JetBrains Mono, Crimson Pro) — see
`tokens/fonts.css`. No binaries required, no substitutions made.

Drop real assets here and they'll be wired into the gallery header and figure frames.
